# Cute ORB

3D mascot playground — Blender assets, inspiration references, and **Visage**, a React + Three.js character exhibition.

## Visage

```bash
cd visage
npm install
npm run dev
```

Brand line: **Soft faces for sharp systems.**

- Landing exhibition with Portrait, Green Blob, and Mallow
- `#studio/portrait` · `#studio/blob` · `#studio/mallow`
- Integration notes at `visage/public/integration.md`

## Green Blob (Blender)

```bash
cd mascot/green-blob
blender --background --factory-startup --python build_green_blob.py
```

# Mascotty

3D mascot playground — Blender assets, inspiration references, and **Mascotty**, a React + Three.js character exhibition.

## Mascotty

```bash
cd visage
npm install
npm run dev
```

Brand line: **Soft faces for sharp systems.**

- Landing exhibition with Portrait, Green Blob, and Mallow
- `#studio/portrait` · `#studio/blob` · `#studio/mallow`
- [Developer documentation](https://kushwaha-pankaj.github.io/cute-orb/#docs/quick-start) with API, React, deployment and contribution guides

## Green Blob (Blender)

```bash
cd mascot/green-blob
blender --background --factory-startup --python build_green_blob.py
```
